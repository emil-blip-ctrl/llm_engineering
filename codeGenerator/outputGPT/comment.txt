I updated the ACE application to add the missing end-to-end synchronous wiring and a first-pass error-handling implementation for the 3 endpoints.

  - common-integration-shlib-datavalue-transcoding

  - REST start -> request preparation -> FSM call -> response translation -> REST end

  - FSM error terminal -> central error handler -> REST end

- Updated the OpenAPI schema to:
  - use a generic JSON object payload
  - expose 400/401/403/422/429/502/504/500 responses
