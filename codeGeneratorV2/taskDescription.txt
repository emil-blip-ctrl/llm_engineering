CAS is going live in 2 phases. In the first phase, B2C Cases will be managed by SFCAS and other cases (B2B) will stay on Assys. 

This story describe how flows will be redirect to the back-end applications, based on the endpoint called and the content of the request.

Theses rules are to be defined in “services-integration-assistance-cases-facade”.


Incoming rules

The rules must be processed in the following order, and the program stopped on the first rule which evaluate to true. 
Basicaly this is like a CASE loop where the first case that evaluates to TRUE you exist the loop. 

When you check field for a value, always do it case insensitive -> UCASE(element) = 'VALUE'
